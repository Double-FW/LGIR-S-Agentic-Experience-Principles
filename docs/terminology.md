# Terms used in this repository

These are working explanations for this draft. External standards retain their authoritative meanings. This repository is usable without an unpublished glossary or a private source.

| Term | Meaning here | Preserve this distinction |
| --- | --- | --- |
| LGIR+S | Legible, Governable, Interpretable, Robust plus Satisfactory | Four enabling principles and an overarching experience outcome principle |
| Agentic POUR | An explanatory analogy for LGIR | Not an official WCAG amendment or equivalence claim |
| Agentic system | A system interpreting goals and coordinating information or actions within delegated scope | The label does not grant authority or establish competence |
| Co-agency | The working relationship and division of activity/control between people and agents | Human presence is not necessarily effective oversight |
| Capability | What an operation is described and implemented to do | Capability is not permission |
| Intent | The operative goal and material expected effects | A generated plan is not approval |
| State | The observed/pending execution condition with relevant evidence | Prediction is not an observed result |
| Commitment | The boundary at which an action produces a consequential effect | A preview or draft can be distinct from commitment |
| Outcome unknown | Available evidence does not establish the effect | Not the same as failed with no effect |
| Reversible | Supported restoration within a defined boundary | A checkpoint cannot undo every external effect |
| Compensatable | A correcting action can address some consequences | Compensation is not erasure |
| Irreversible | No supported complete reversal exists for the relevant effect | Requires honest pre-commit control and remedy, not a fictional Undo |
| Provenance | Source origin, revision and transformations with relevant context | A URL alone does not establish quality, rights or currency |
| Calibration | A relationship between a stated uncertainty measure and evaluated outcomes in a defined context | Self-reported confidence is not automatically a calibrated probability |
| Satisfactory | The experience principle about intended outcomes, quality, effort and treatment | Not a favourable rating alone |
| Satisfaction | A person's assessment, with reasons and context | Not proof of correctness, conformance or security |
| Comparable experience | Fair opportunity across relevant quality, effort, privacy, dignity and control dimensions | Comparable need not mean identical |
| Evidence | Material supporting a stated question with origin, method and limits | Synthetic examples and completed templates are not actual execution evidence |
| Local A/AA | Proposed priority labels for this draft | Not WCAG levels, legal requirements or validated LGIR+S conformance |

See [design history](design-history-and-crosswalk.md) for how the owner's original agentic ideas were developed into this edition.
